Elementos de un formulario Web

HTML ofrece diferentes controles...

Campo de texto

Permite escribir una línea de texto <input type="text">

Contraseña

Texto oculto por seguridad <input type="password">

Correo electrónico

Para direcciones de email <input type="email">

Número

Permite introducir numeros <input type="number">

Teléfono

Para número de teléfono <input type="tel">

URL

Para dirreciones web <input type="url">

Búsqueda

Campo de búsqueda <input type="search">

Fecha

Permite introducir fecha <input type="date">

Hora

Selector de hora <input type="time">

Semana

Selector de semana <input type="week">

Mes

Selector de mes <input type="month">

Fecha y Hora

Selector de fecha y hora <input type="datetime-local">

Color

Selector de color <input type="color">

Rango

Selector de un valor en un rango <input type="range">

Checkbox

Casilla de verificación <input type="checkbox">
